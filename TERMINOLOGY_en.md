# Terminology and tagging conventions

Kept as its own file so tags stay consistent across hundreds of entries instead of drifting slug by slug. If you need a tag that isn't listed here, propose it in your PR description rather than inventing it silently — it gets added here once agreed, then reused.

## Canonical `era` tags

| Tag | Covers |
|---|---|
| `precolonial` | Before 1841 |
| `colonial-era` | 1841–1941, general |
| `wwii-japanese-occupation` | 1941–1945 |
| `post-war-1960s` | Late 1940s–1960s |
| `1970s` | |
| `1980s` | |
| `handover-1997` | Lead-up to and immediate aftermath of the 1997 handover |
| `post-1997` | General post-handover, when no more specific tag applies |
| `2003-sars` | |
| `2014-umbrella-movement` | |
| `2019-protests` | |
| `post-2020` | National Security Law era onward, when no more specific tag applies |

A book can carry multiple era tags if it genuinely spans periods (e.g. a family saga) — that's normal, not an error.

## Naming conventions

- "Hong Kong" in prose, not "HongKong" or "HK" — `HK` is fine as a slug/tag component only.
- Cantonese romanization: use **Jyutping** for new terms unless a term already has a dominant, widely recognized alternate romanization (e.g. "dim sum," not the Jyutping form) — when in doubt, follow how the term is spelled in major English-language sources about Hong Kong.
- Traditional Chinese characters throughout zh-HK content — never simplified, matching the SSOT language decision.
- Dates: full year in frontmatter (`year: 1963`), not decades or ranges — use `era:` tags for periods instead.

## Slugs

Lowercase, hyphen-separated, derived from the English title or a transliteration if no English title exists. E.g. `the-drunkard`, `wo-cheng` for 我城 if no standard English title is in use.
